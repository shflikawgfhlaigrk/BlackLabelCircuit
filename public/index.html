Your codebase, graded like a senior reviewer and wired in 3D. Here's how to read it:

    
    
      
  • Each dot is a file. Bigger = more lines of code. Its color is that file's grade — green A through red F.
    • 
      
  • Lines are dependencies. One file importing another. Particles flow in the direction the code depends.
    • 
      
  • ◈Red crystals are broken wires. Something is imported that doesn't exist — a dead or missing file.
    • 
      
  • ➤Click any file for its report card: grade, six review dimensions, and every finding written like a code-review comment with line numbers.
    • 
    

    
The sidebar has your overall grade, a grade breakdown you can filter, and the worst offenders. Press / to search files, Esc to close. Drag to orbit, scroll to zoom.

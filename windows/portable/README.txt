BLACK LABEL CIRCUIT - PORTABLE WINDOWS

1. Double-click "Launch Circuit.cmd".
2. Type or paste the path of the source-code folder you want Circuit to inspect (a Git repository).
3. Circuit starts its local service in a console window and opens the buyer interface at http://127.0.0.1:8923/ in your default browser. If the browser does not open, visit that address yourself.

Circuit analyzes the selected local repository and renders its dependency graph and code-quality report. It does not install system services. Close the console window to stop the local service.

This package is unsigned. Windows may display its normal publisher warning.
